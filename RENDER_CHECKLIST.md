- [ ] `whitenoise` in requirements.txt

### Database
- [ ] Database name: `ofcnet_db`

- [ ] `SECRET_KEY` - will be auto-generated by Render

## 🔍 If Deployment Fails

### Immediate Actions
- [ ] Check build/start logs in Render dashboard
- [ ] Note the exact error message
- [ ] Search in DEPLOYMENT_GUIDE.md for that error
- [ ] Try "Manual Deploy" after 1 minute

### Build Phase Failed?
- [ ] Check if all requirements in `requirements.txt` exist
- [ ] Verify no typos in requirements
- [ ] Check Python version compatibility
- [ ] Look for version conflicts

### Start Phase Failed?
- [ ] Check if migrations ran (should see "completed successfully")
- [ ] Look for database connection errors
- [ ] Check if Django settings are parsing env vars correctly
- [ ] Verify `python -m gunicorn` output in logs

### Application Won't Start?
- [ ] Wait 1-2 minutes (free tier needs time)
- [ ] Check if database service status is "Available"
- [ ] Try clicking "Manual Deploy" again
- [ ] Check for Python syntax errors in settings.py

### Everything Looks OK But Still Fails?
- [ ] Read full error message carefully
- [ ] Search error in DEPLOYMENT_GUIDE.md
- [ ] Try rolling back to previous commit if recently changed
- [ ] Test locally: `python manage.py check`

### ❌ Failed Build Examples

**Missing Package:**
```
ERROR: Could not find a version that satisfies the requirement django-leaflet==0.33.0
```
→ Check if package exists with that version number

**Syntax Error:**
```
File "nwo_portal/settings.py", line 45, in <module>
    INVALID SYNTAX HERE
SyntaxError: invalid syntax
```
→ Fix Python syntax in settings.py

**Permission Denied:**
```
Permission denied: 'bash build.sh'
```
→ Script file permissions issue (should auto-fix in Render)

### ✅ Successful Start Log
```
[2026-05-24 10:30:45] Starting NWO Portal application
[2026-05-24 10:30:45] Database URL: postgres://***

```

### ❌ Failed Start Examples

**Database Error:**
```
psycopg2.OperationalError: could not translate host name "ofcnet_db" to address
```
→ Wait 30 seconds, database is initializing

**Migration Error:**
```
django.db.utils.ProgrammingError: relation "inventory_equipment" does not exist
```
→ Check migrations in inventory/migrations/

**Environment Variable Missing:**
```
KeyError: 'DATABASE_URL'
```
→ Verify env var is linked from database service

## ⚡ Quick Fixes

| Problem | Fix |
|---------|-----|
| "Invalid credentials on login" | Run `python manage.py fix_user_passwords` on deployed instance |
| "App sleeping" | Free tier spins down after 15 min. Make a request to wake it up |
| "Build timeout" | Reduce workers in gunicorn config or upgrade plan |
| "Out of memory" | Free tier has 0.5 GB. Optimize queries or upgrade |
| "Static files 404" | Run `python manage.py collectstatic --clear` locally and push |
| "Database won't connect" | Restart database service from Render dashboard |
